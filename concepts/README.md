# ホームのデザイン3案（プレビュー用）

どの案も「場所・営業時間・予約・メニューに迷わずたどり着く」を最優先にしています。文章は今のサイトのもの（日本語のみ）。

## A 今すぐ行ける（a.html）
- 主役：駅の案内板のような営業状況ボード。開くと3店舗が1行ずつ並び、東京時間で「営業中・準備中・終了・定休」を表示（祝日・臨時休業は未対応）。
- 色：紺 #10243e、営業中の緑 #2fbf71、準備中の黄 #f2b33d、予約のピンク #e0245e、白。
- 書体：BIZ UDPゴシック（公共サインにも使われる読みやすいUD書体）1種類。
- 使い勝手：画面下に「店舗・メニュー・予約・安心情報」の固定バー。アレルギーの疑問はQ&Aで開閉。

## B 物語（b.html）
- 主役：料理写真の全面に、縦書きの見出し「食の制限から、可能性を味わう。」。
- 色：白、藍 #26335a、墨 #1c1d22、予約のピンク。
- 書体：見出しはしっぽり明朝、本文はNoto Sans JP。
- 使い勝手：メニューは全画面の目次で開く。店舗は横にめくる。予約ボタンは常に右下。

## C 元気（c.html）
- 主役：ピンクの面に大きな文字、丸く切り抜いた料理写真と「アジア初」「東京No.1」のシール。
- 色：ピンク #e0245e、紺 #1d3557、黄 #ffd23f、白。
- 書体：M PLUS Rounded 1c（丸ゴシック）1種類。
- 使い勝手：店舗は大きなボタンで切り替え。動きは流れる帯の1か所だけ（動きを減らす設定では止まる）。
